# مكتب حبيب — QR Landing Page

صفحة تعريفية خفيفة لمكتب حبيب، وكيل شركة التبادل للدفع الإلكتروني.

## التشغيل


## GitHub Pages

Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## ملاحظات

- الصفحة Mobile-first وRTL.
- الـQR يجب أن يشير إلى رابط GitHub Pages النهائي، وليس إلى حساب اجتماعي مباشر.
- عند تغيير معلومات الصفحة، يبقى رابط الصفحة نفسه وبالتالي يبقى الـQR صالحاً.
- رابط Facebook لم يتم تضمينه لأن الرابط الفعلي للحساب لم يُزوّد بعد.
- صورة `assets/habeeb-office-banner.png` هي الصورة التي سلّمها العميل كما هي.
